# Consumer_price_index
This project involves the development of a Machine Learning model to predict the Consumer Price Index (CPI) based on historical economic data. CPI is a key economic indicator used to measure inflation by tracking changes in the average prices of a basket of consumer goods and services over time.



📊 Consumer Price Index (CPI) Prediction Using Machine Learning
📌 Project Overview

This project focuses on building a Machine Learning model to predict the Consumer Price Index (CPI) using historical economic data. CPI is a crucial indicator of inflation, reflecting changes in the cost of a standard basket of consumer goods and services over time.

The model analyzes historical CPI trends to forecast future values and support economic analysis and decision-making.

🎯 Objectives

Analyze historical CPI data

Build a machine learning regression model for CPI prediction

Forecast future CPI values

Evaluate model performance using standard metrics
